EVERHOUR DESKTOP WIDGET  (v8.7)
===============================

Shows the Everhour task you are tracking, live, on your desktop.
No admin rights needed.


SETTING IT UP (one minute, once)
--------------------------------
Double-click:  Install Everhour Widget.vbs
   (copies the widget to your user folder and starts it - this folder can
   be deleted afterwards)
...or, to run it straight from this folder:  Start Everhour Widget.vbs

A short animated guide then shows you exactly where your API token is in
Everhour (your name at the bottom-left > My Profile > Application Access >
copy API Token), checks it, and asks a few questions to make the widget
yours.

The widget starts by itself every time you log in to Windows - silently,
with no black console windows. Nothing appears in your taskbar.

Open it any time: press Win+R, type  Everhour  and press Enter. If it is
already running it slides out and comes to the front.


GIVING IT TO SOMEONE ELSE
-------------------------
Run:  Build Share Folder.bat
It makes  Share\Everhour Widget  and  Share\Everhour Widget.zip.
Send either one. On their laptop they double-click
"Install Everhour Widget.vbs". Your API token is NOT included - it lives
only on your PC.


WHAT THE COLOURS MEAN
---------------------
  Your theme colour    a timer is running. The dots round the edge fill up
                       once a minute.
  Teal, with a cup     you're on a break (a task whose name contains
                       "break" or "lunch" - change the words in Settings).
                       The bar shows how much of your daily break is used.
  Red / orange, fast   your breaks today went over the allowance (1 hour by
                       default).
  Red, a dot circling  no timer is running. The big timer shows how long
                       it has been off (from when you clocked in, at most).
  Night blue, a clock  you are clocked out: nothing counts and nothing
                       turns red until you clock in again.


USING IT
--------
  Round button       start / stop. When nothing is running it resumes the
                     last task you tracked (hover it to see which one).
  Click              Wide / Square: open today's list (Large always shows it)
  Click and drag     move it anywhere, on any monitor - it remembers the spot
                     and never goes off screen
  Right-click        menu: start, resume, stop, refresh, open Everhour,
                     change shape, settings, setup guide, exit
  Ctrl+Alt+E         start / stop from anywhere (change it in Settings)
  Win+R, Everhour    opens the widget / brings it to the front


CLOCK IN AND CLOCK OUT  (Everhour timecards)
--------------------------------------------
  Clock in / Clock out  the button next to Stop (or right-click the widget).
                        Clocking out stops a running timer first.
  Clocked out           the widget rests in night blue and does not count
                        the time off.
  Clocked in elsewhere  clock in from the Everhour website or app and the
                        widget follows within about 15 seconds.
  Turn it off           Settings -> Widget -> Clock in / clock out


SHAPES AND AUTO-HIDE
--------------------
  Large (default)   phone-widget style, today's tasks always visible
  Square            compact; click to open the list
  Wide              slim bar; click to open the list
  Auto-hide         slides into the screen edge when you're not using it;
                    a dot strip keeps showing the status - hover to bring
                    it back


MAKING IT YOURS
---------------
Right-click -> Settings. Everything saves the moment you change it:
  - Look: theme, shape, font (Inter = iPhone style, Doto = Nothing dots...),
    text size S / M / L, background glass or solid
  - Widget: always on top, hide from screen sharing, auto-hide, seconds,
    progress bar, ask before switching, clock in / out, start with Windows
  - Focus: animations, edge lights, red when stopped, breaks
  - Work hours (scroll wheels), work days and reminders
  - Advanced: daily target, refresh speed, auto-collapse, keyboard shortcut
  - Account: change token, test connection, setup guide, log folder


CHECKING IT WILL START WHEN YOU POWER ON
----------------------------------------
Run:  Test Autostart Now.bat
The widget starts at sign-in from two places (the Run list and a sign-in
task), so it still comes up if one of them is blocked.


IF IT DOES NOT APPEAR
---------------------
Run:  Troubleshoot.bat  - it saves troubleshoot-log.txt (never contains
your token). Send that file to whoever gave you this.


YOUR TOKEN AND YOUR DATA
------------------------
Your API token is stored only on this PC, encrypted for your Windows user,
in  %APPDATA%\EverhourWidget\config.json.  It is sent only to
api.everhour.com. The widget only ever sees your own time.

To revoke it: Everhour -> My Profile -> Application Access -> Reset Token.


TURNING IT OFF
--------------
  Just for now          right-click the widget -> Exit (or Stop Widget.bat)
  Stop it starting up   Settings -> Widget -> turn off "Start with Windows"


FAVOURITES, FOCUS AND MORE  (right-click the widget)
----------------------------------------------------
  Favourites         star up to 5 tasks in the task picker; they show as
                     one-click "Quick switch" chips on the widget
  Focus              25 / 50 min focus session; the edge lights count down,
                     then a chime and a break (it can switch to your break
                     task and back for you - Settings -> Focus sessions)
  Edit note...       change the note on the running entry
  Add missed time... add time you forgot to track, to any task and day
  Sounds             soft chimes; turn off in Settings -> Widget


UPDATES
-------
From version 7 the widget updates itself: when a new version is out you
get a "Widget update available" message - click it (or right-click ->
Install update). Settings and token are kept.

Still on version 6 or older? Download the new zip, unzip it and
double-click "Install Everhour Widget.vbs" once. After that, updates are
automatic.
