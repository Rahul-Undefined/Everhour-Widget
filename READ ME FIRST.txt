EVERHOUR DESKTOP WIDGET  (v4)
=============================

Shows the Everhour task you are tracking, live, on your desktop.
Nothing is installed. No admin rights needed.


SETTING IT UP (one minute, once)
--------------------------------
1. Get your personal Everhour API key:
      Open Everhour -> click your avatar (top right) -> Settings -> API
      Copy the key.

2. Double-click:  Start Everhour Widget.vbs

3. Paste your key and press Connect. The widget checks the key with
   Everhour straight away and tells you if it is wrong.

That is it. The widget appears in the bottom-right of your desktop and will
start by itself every time you log in to Windows. Nothing appears in your
taskbar - there is no window to accidentally close.

IMPORTANT: always start it with the .vbs file. Do not double-click the
.ps1 file directly - Windows blocks that by default and nothing happens.


USING IT
--------
  Round button       start / stop. When nothing is running it resumes the
                     last task you tracked (hover it to see which one).
  Click              expand: today's time task by task, this week's total,
                     and Start / Stop / Settings buttons.
                     (it shrinks back on its own once you move away)
  Click and drag     move it anywhere, on any monitor - it remembers the spot
  Right-click        menu: start a timer, resume, stop, refresh, open
                     Everhour, settings, exit
  Ctrl+Alt+E         start / stop from anywhere (change it in Settings)

The bar under the timer fills up towards your daily target (8h by default).
If Everhour can't be reached, a small "offline" tag appears and the timer
keeps counting.


MAKING IT YOURS
---------------
Right-click -> Settings. Pick a ready-made theme (Graphite, Midnight,
Forest, Sunset, Light) or set every colour yourself; background opacity,
font, size, corner roundness; daily target; refresh speed; the keyboard
shortcut; and reminders when no timer is running in your work hours and
work days.

Changes show on the widget as you make them. Save keeps them, Cancel puts
everything back, Reset returns to the defaults.


CHECKING IT WILL START WHEN YOU POWER ON
----------------------------------------
Run:  Test Autostart Now.bat

It closes the widget, then starts it again using the exact command Windows
runs at login, and tells you PASS or FAIL. No reboot needed to find out.


IF IT DOES NOT APPEAR
---------------------
Run:  Troubleshoot.bat

It checks this PC, the startup entry and your API key, and says plainly
whether autostart is configured and whether your key works. It saves
troubleshoot-log.txt - send that file to whoever gave you this.
(The log never contains your API key.)


YOUR KEY AND YOUR DATA
----------------------
Your API key is stored only on this PC, encrypted for your Windows user,
in:
    %APPDATA%\EverhourWidget\config.json
It is sent only to api.everhour.com. The widget only ever sees your own
time - not your colleagues.

Do not share your API key. To revoke it, go to Everhour -> Settings -> API.


TURNING IT OFF
--------------
  Just for now          right-click the widget -> Exit
                        (or run Stop Widget.bat)
  Stop it starting up   right-click -> Settings -> turn off
                        "Start automatically when Windows starts"


MOVING THIS FOLDER
------------------
Safe to move. Start the widget once from the new location and it updates
its own startup entry automatically.
